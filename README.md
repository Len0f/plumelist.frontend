# Plumelist — Frontend

Interface utilisateur du projet Plumelist, une application de gestion et de suivi d'écrits de roleplay. Permet aux utilisateurs de créer, organiser et suivre leurs écrits collaboratifs.

Lien : [https://plumelist-frontend.vercel.app](https://plumelist-frontend.vercel.app)

## Technologies

- **Framework** : Next.js 12
- **UI** : React 18, Ant Design 5
- **Etat global** : Redux Toolkit, React-Redux, Redux Persist
- **Tests** : Jest, Testing Library
- **Langage** : JavaScript
- **Déploiement** : Vercel

## Fonctionnalites

- Inscription et connexion utilisateur
- Tableau de bord de suivi des écrits de roleplay
- Persistance de l'état utilisateur entre les sessions (Redux Persist)
- Interface construite avec les composants Ant Design
- Tests unitaires avec Jest et Testing Library

## Structure du projet

- `components/` — Composants React réutilisables
- `pages/` — Pages Next.js (routing automatique)
- `public/` — Fichiers statiques
- `reducers/` — Reducers Redux
- `styles/` — Fichiers CSS
- `jest.config.js` — Configuration des tests
- `next.config.js` — Configuration Next.js
